# 学习通助手 3.4 安装与验证

配套文件：`chaoxing-helper-improved.user.js`。

本版本根据你提供的学习通脚本重写，适用于 Edge 桌面浏览器中的 Tampermonkey。它不是学习通手机 App 插件。已经通过 JavaScript 语法检查及 37 项针对性测试，其中 28 项在本地 Edge 测试页验证，包含使用本地真实媒体文件验证加载和播放进度。尚未登录你的课程进行实际页面验证。

## 从 3.0—3.3 更新

在篡改猴管理面板打开旧的“学习通播放与答题助手（改进版）”，将代码全部替换为当前配套文件的内容，Ctrl+S 保存，再刷新课程页面。面板标题应为“学习通助手 · 3.4”。不要同时启用两个版本。如果现在正停留在“确认提交？”弹窗，可先手动点击弹窗右侧的提交，完成当前这次提交，再更新和刷新。已经显示“我的答案”和逐题得分的结果页，更新后刷新即可重新识别，无需重新答题。

3.1 修复了提交按钮在题目容器外、提交按钮延迟出现/禁用、题目被确认弹窗替换后不继续确认等情况。倍速优先通过网站菜单或播放器设置应用；检测到倍速导致持续暂停或被重置时，回退 1 倍并显示具体原因。

3.2 针对你截图里的“提示 → 确认提交？ → 取消 / 提交”弹窗补充修复：即使弹窗没有已知样式名，也可依据确认正文和浮层内按钮定位；即使题目在 iframe、弹窗在外层页面，或此前已等待超时，也能处理确认。只点击该弹窗中的提交，同一弹窗不连续重复点击；确认结果会同步给答题页面。

3.3 修复提交成功后卡在逐题结果页的问题：联合识别“我的答案”和该题实际得分，避免把已经出分的题目当成待答题；无需依赖页面有“提交成功”或“本次成绩”标题。识别完成后显示 5 秒换课倒计时，支持自绘的“下一节”按钮。结果页在 iframe、下一节在外层页面也会传递完成状态。仍有可编辑题目、可用提交按钮、只有满分提示或部分题目出分时，不据此自动换课。

3.4 修复换课后停在黑色播放器中央播放按钮、显示 0/0 的问题：先启动播放器，不再等到媒体已经加载好才调用播放；支持视频元素暂时隐藏、点击开始后才创建视频的情况。视频开始后才设置倍速，避免把未加载状态误判为网站重置倍速。面板分别显示加载、播放、需要手动播放和加载错误。播放器按钮最多自动尝试 3 次，播放请求最多尝试 5 次，尚未完成的播放请求不会重复堆积；停止后也不会因为旧请求完成而重新播放。

## 安装

1. 在 Edge 中安装 Tampermonkey（篡改猴）：https://www.tampermonkey.net/ 。
2. 在地址栏输入 `edge://extensions/`，确认扩展已开启，并有访问学习通课程网站的权限。若提示需要用户脚本权限，按扩展提示开启“允许用户脚本”或“开发人员模式”。官方说明：https://www.tampermonkey.net/faq.php?locale=en&q=Q209 。
3. 在篡改猴管理面板关闭旧的超星/学习通脚本，包括你提供的 2.1.0 版本。只启用一个课程助手，避免重复点击。
4. 点击篡改猴图标 → 添加新脚本，删除默认内容。
5. 打开 `chaoxing-helper-improved.user.js`，复制全部代码到编辑器，按 Ctrl+S 保存，确认脚本已启用。
6. 登录学习通网页端，打开实际课程视频页面，然后刷新。右上角应出现“学习通助手 · 3.4”面板。
7. 首次使用先保持 1 倍速，点击面板“开始”。如果浏览器拦截自动播放，手动点击视频播放按钮。

## 面板

- 开始/停止：控制自动操作。停止时暂停已接管的视频，取消尚未执行的延迟点击；已发出的提交不能撤回。
- 倍速：1、1.1、1.25、1.5、2 倍。优先使用网站自带的倍速选项，面板分别显示目标倍速、实际倍速和暂停状态。倍速导致反复暂停或被页面重置时回退 1 倍，当前视频不再自动反复尝试同一目标倍速。可手动选择其他倍速重新试验。网站能否计入进度需实测，没有“1.1 倍保证安全”的假设，也不能保证被课程限制的倍速有效。
- 自动播放/恢复：先点击播放器的开始按钮并尝试加载播放，播放中暂停后尝试续播。视频尚未加载时显示“时长待加载”，不提前尝试倍速。若浏览器要求真实用户操作，会提示手动点击视频中央播放按钮一次。若要持续手动暂停，请先点击“停止”。
- 防切屏暂停：运行期间拦截文档可见性和窗口失焦事件；网站采用其他检测方式、浏览器冻结页面或电脑休眠时不保证有效。
- 自动下一节：收到视频真实结束状态或识别到测验已提交/逐题出分，且当前报告中没有待处理题目后，显示倒计时并等待至少 5 秒再点击下一节。等待不等于确认服务器已将所有任务点记为完成，必须检查课程目录。同一页面的下一节只自动点击一次；关闭自动下一节或点击停止会取消倒计时。
- 自动答题：对已识别的选择题选取选项并尝试提交，不接入题库，不保证答对。多选题识别到“至少选择 N 项”时尽量满足要求，否则至少选择一项。选项填好后等待提交按钮出现或启用，最多等待 15 秒；可处理题目外的提交按钮、自绘按钮和页面中的确认提交弹窗。同步点击触发的原生提交确认会在本次点击内确认，异步弹出的浏览器原生确认可能仍需手动处理。
- 在当前课程和当前标签页中记住设置及运行状态，同课程刷新/换节可续播；切换不同课程或新会话需要检查面板状态。

## 先验证一节课

1. 点击开始，确认视频播放、实际倍速与设置一致。
2. 点击停止，确认不再自动续播；再点击开始恢复。
3. 遇到题目，检查是否真的选中答案、提交、确认并出现结果。章节测验出分后应出现换课倒计时，随后进入下一节；视频弹题则应继续播放。
4. 等视频自然结束，确认只进入一次下一节，没有跳过章节。
5. 刷新课程目录，确认网站仍将上一节标记为已完成。
6. 上述流程通过后，再试其他倍速。

## 未识别时的行为

- 未识别题目、填空/简答：保留页面并显示原因，不把题目自动跳过。
- 等待 15 秒仍未找到可用提交按钮：显示原因；可提供提交区域截图进一步适配。
- 提交 15 秒后仍未确认结果：不重复提交，等待手动处理。
- 如果随后出现明确的“确认提交？”弹窗，仍会继续确认；自动答题关闭或脚本停止时不会自动点击。
- 答错且网站不允许继续：可能需要手动作答；随机选项无法保证通过。
- 找不到下一节：提示检查目录，可能是最后一节，也可能是选择器不匹配。
- 嵌套页面需要每层相关 frame 都能加载脚本并转发状态。如果课程使用未覆盖的域名或路径，需要具体页面信息再适配。
- 本版只识别特定的题目容器、选择题选项和完成提示；不同版本的章节测验不保证全部支持。

## 提供故障信息

把课程页地址（可去掉账号等个人信息）、面板提示和对应页面截图发到当前 Codex 对话。不要提供账号密码或 Cookie。

需要进一步诊断时：按 F12 → 控制台，手动输入 `CXHelperV3.diagnostic()`。返回的信息包含配置、实际倍速/暂停状态、题目处理阶段、可见提交按钮的标签/样式及 iframe 域名，不包含账号密码。顶层页面也会汇总子页面的诊断。控制台若选中了其他 frame，应先切回课程顶层页面。

如果页面改版，优先调整脚本顶部 `SEL` 中的按钮、题目容器和课程目录定位规则。所有调整仍需在真实课程上验证。
